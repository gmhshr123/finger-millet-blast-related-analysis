Deletions relative to E2 in finger millet-infecting Magnaporthe oryzae (MoE)

Interactive figures and the deletion database. Each page is self-contained and opens in a web browser.

  • Heat map of all-base deletions in 226 strains Fraction of the uniquely mappable bases deleted per window, one row per strain.
  • Heat map of SNP-based deletions in 226 strains Fraction of the SNPs per window that lie in a run of at least five consecutive missing SNP calls, one row per strain.
  • Deletion tracks along E2 in 33 Ethiopian strains All-base and SNP-based deletions, deletions with directly joined flanks, deletions with a TE at an end, SNP density, repeat fraction and effector genes, per window.
  • Deletion database Every all-base deletion in the 33 Ethiopian strains, with its breakpoints, read evidence and the sequence at each end (about 23 MB; loading takes a few seconds).
